JWT:
---
JWT is a string of text. that the server sends to client when user log in. then the client sends this "passport" back in the header
of every future request.

Header: tells the php which algorithm was used.
payload: The actual data. Usually this is the user_id and the expiration_time.
signature: signature is a secret seal. php takes the payload and header, and add a secret key. and hashesh them. 
when the hacker try to change user_id in the payload. the signature won't match. the php will reject the token.
