------------------------------------------------

✔ Encapsulation
++++++++++++++++++

Private properties + public methods.

class User {
    private $name;

    public function setName($name) {
        $this->name = $name;
    }

    public function getName() {
        return $this->name;
    }
}

Explain WHY private is used.

Explanation:
-------------

In your example, using private is all about protection and control. If you made $name public, anyone could bypass your setName method and change the data directly, which often leads to "dirty" data or bugs.

Here is why private is the standard choice in this scenario:

1. Data Validation (The Filter)
If $name is private, the only way to change it is through setName(). This gives you the power to enforce rules.

If it were public, someone could set the name to an empty string, an array, or even a malicious script. With private, you can do this:

PHP
public function setName($name) {
    if (strlen($name) < 2) {
        throw new Exception("Name is too short!");
    }
    $this->name = htmlspecialchars($name); // Security: prevent XSS
}
